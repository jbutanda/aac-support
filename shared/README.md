# Shared files for the AAC tools

`core.js` holds the 60-word demo board (words, Spanish labels, color groups), speech and voice picking, confetti, the language toggle and small helpers. `base.css` holds the shared look. Every tool in this repo loads both, so a change here updates all of them.

Symbols in `symbols/` and `../talker/symbols/`: OpenMoji (https://openmoji.org), CC BY-SA 4.0.
